The root Makefile is the single build entry point that compiles all `src/*.c` into object files under `build/`, links them into the `coalesce` executable, and then reuses those objects (minus `main.o`) to link each `tests/test_phaseN.c` into separate test binaries. Cross-child wiring is purely build-time: the `ssh_library` source tree provides the shared objects (`buffer`, `aes`, `kex`, `sha256`, `sha512`, `fe25519`, `curve25519`, `ed25519`, `base64`, `rand`, etc.) that every test phase links against, while each test supplies its own `main()`. OS differences (Windows vs POSIX) are handled centrally in the Makefile via `IS_WINDOWS` detection, so both the library and tests share one cross-platform build contract.
