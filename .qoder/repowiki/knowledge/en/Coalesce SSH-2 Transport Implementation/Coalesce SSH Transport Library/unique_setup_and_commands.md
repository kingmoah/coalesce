The built binary supports two modes: `coalesce serve [port]` starts a TCP server listening on `0.0.0.0:<port>` (default 22) and echoes back an `SSH_MSG_DEBUG` after receiving the first plaintext packet; `coalesce connect user@host[:port]` connects as a client, exchanges banners, sends `SSH_MSG_IGNORE`, then prints any received reply. Both paths call `net_init()`/`net_shutdown()` around the whole run.
