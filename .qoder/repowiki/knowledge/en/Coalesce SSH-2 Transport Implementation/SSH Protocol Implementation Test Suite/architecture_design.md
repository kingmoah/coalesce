Four independent single-file C programs, each a self-contained `main()` that links against the project's `src/` headers via relative includes (`../src/...`). They are organized by development phase: `test_phase1.c` exercises the wire-format buffer API (`ssh_buf_t`, mpint per RFC 4251 §5); `test_phase2.c` covers SHA-256/SHA-512 (FIPS 180-4), Ed25519 (RFC 8032 §7.1), Curve25519/X25519 (RFC 7748 §6.1), AES-CTR/FIPS-197, base64 (RFC 4648), OS entropy, and KEXINIT negotiation; `test_c25519_debug.c` is an in-process reference implementation of `curve25519_eval` used to cross-check the library's field arithmetic; `test_phase3.c` drives the session layer over a real loopback socket pair, exercising identification banner validation, key installation, plaintext/encrypted packet framing, MAC enforcement, and malformed-packet rejection per RFC 4253. Each test file owns its own helpers (e.g. `hex_to_bytes`, `expect_hex`, `make_pair`) and asserts pass/fail via `assert()` plus `printf` status lines.
